# scaffold

Met en place (ou vérifie) le scaffold standard du repo ops-tools.

## Objectif
- Créer la structure de dossiers
- Ajouter .gitattributes et .editorconfig (LF)
- Installer Makefile + README de base
- Préparer runbooks + scripts initiaux

## Préconditions
- Être à la racine du repo ops-tools
- Git installé

## Steps
1) Vérifier l'arborescence attendue
2) Créer les dossiers manquants
3) Vérifier/installer .gitattributes + .editorconfig
4) Afficher `git status` et `git diff`

## Run
- bash: pwd
- bash: ls -la
- bash: git status
